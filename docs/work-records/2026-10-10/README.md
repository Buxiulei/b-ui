## 范围与读法

此次上传的是文档和证据索引。公开仓库已有的基线代码与较新的本地未提交实现明确分开；后者的源码路径只是交接定位，不暗示文件已经包含在此次提交中。需要恢复实验时，应取得产物索引对应的私有源快照，不能用 README 的文字重建验证资格。

本轮固定 sing-box 1.14.2，由 Rust 负责控制和管理，目标坚持上游原版内核、不维护定制协议源码。当前发布锁仍记录上游源码加 `with_v2ray_api` 计量标签的自建产物，不等同于官方发布归档原件；两者分别记账，迁移官方分发还须通过[计量与撤权验收 G0](managed-client-design.md#原版发行物与计量迁移前置-g0)。早期探索中的内核修改、规则绕行、客户端手工修补或多版本兼容尝试，不能自动成为当前交付方案。

历史研究、当时的测试结果和当前待完成工作分开记录。所有测试数字保留源码范围，未运行与 ignored 不算通过；一次错误日志、一个 IPv6 地址或一次成功请求不单独证明断网原因、真实 IP 泄漏或完整保护。

## 接手入口

先阅读架构文档的剩余入口表，再按验证台账定位对应快照。下一步先完成隔离监督器的实际入口和停止前的 systemd 实例代次校验，通过完整审查后验证私有 PID1 启动与清理；之后再推进 Rust warm/StopPost、Start/Restart、所有写者、冷启动及故障矩阵。不要跳过这些步骤直接部署 4.1.9。

原始诊断与实机回执仍保留在受限目录；本公开记录不包含主机地址、用户凭据、账户信息、进程/容器运行身份或私人目录路径。SHA 用来对应既有证据，不是凭据，也不自动构成可复现或生产验收证明。
