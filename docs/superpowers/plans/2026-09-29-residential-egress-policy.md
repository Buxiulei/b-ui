# 住宅出口策略实施计划

设计依据：[住宅策略跟随实际出口](../specs/2026-09-29-residential-egress-policy-design.md)。用户已要求保持 Rust、提交前轮 PR 后继续架构优化。

1. 保持 PR #1 的审查基线；新分支 `codex/residential-egress-policy` 基于已验证的稳定性提交。
2. 在 schema 定义回环策略端口、稳定 UUID 标签及解析接口；增加边界与资源冲突验证。
3. 先增加失败回归，再把各上游自动黑名单和端口限制移入选中出口对应的策略层；保留 selector 接口与既有 UDP 降级边界。
4. 在日志解析/归因处识别真实 UUID 出口，探测实际拓扑后抑制新拓扑外层派生错误。测试旧连接切换、未知 UUID、API 不可读及旧拓扑兼容。
5. 用真实内核、回环模拟 A/B/直连实现策略隔离和热切回归，同时验证旧连接、half-close、UDP 与新增转发开销。测试不得依赖生产凭据或外网可用性。
6. Linux workspace、fmt、clippy、三版内核 CI、GitNexus 变更影响分析和人工 diff 审查通过后提交独立 PR；PR 描述包含实测结果与仍会重启的配置变更边界。
7. 是否上线取决于验证结果：不将尚有数据路径阻断或明显性能回退的改造部署到正在使用的服务。
